# صيغة بيانات مكتبة أبصار الإسلام — الإصدار 1

هذا المرجع لأي تطبيق خارجي (تطبيق الجوال بـ Flutter وغيره) يقرأ بيانات الموقع مباشرة. كل الملفات JSON بترميز UTF-8، وتُقدَّم من:

```
https://absaralislam.github.io/
```

تُحدَّث البيانات آلياً عند نشر جديد في القنوات (خلال دقائق)، ولا تحتاج مصادقة.

## قواعد الثبات (العقد مع التطبيقات)

1. **المعرّف `id` ثابت إلى الأبد.** لا يتغير معرّف منشور بعد ظهوره، ويصلح مفتاحاً للمحفوظات والإشعارات والتخزين المحلي.
2. **إضافة لا حذف:** قد تُضاف حقول جديدة في أي وقت، فتجاهل ما لا تعرفه. لا يُحذف حقل ولا يتغير معناه ولا نوعه داخل الإصدار نفسه.
3. **`schema_version`** في `data/tg/index.json` و`data/youtube.json`. إن احتاجت الصيغة تغييراً يكسر التوافق رُفع الرقم، وبقيت الصيغة القديمة متاحة مدة انتقالية.
4. **الحقول الاختيارية تُحذف ولا تكون `null`.** غياب الحقل يعني أن القيمة غير موجودة.
5. **التواريخ** بصيغة ISO 8601 بالتوقيت العالمي، مثل `2026-11-09T14:13:52+00:00`. وقد يأتي بعضها تاريخاً فقط، مثل `2026-11-09`.
6. **الروابط في الحقول المنتهية بـ `_url` مطلقة وكاملة** (تبدأ بـ `https://`). أما `img` فحقل قديم نسبي يستعمله الموقع، فاعتمد `image_url` بدلاً منه.

## الملفات

| الملف | المحتوى | الحجم التقريبي |
|---|---|---|
| `data/library.json` | بيانات الموقع، وتعريف البرامج، والسيرة الذاتية، وترتيب قنوات «الفوائد» | صغير |
| `data/tg/index.json` | الفهرس: لكل قناة عدد منشوراتها وأحدثها ووسومها وأسابيعها، مع قائمة الكتب | ~٤٠٠ ك.ب |
| `data/tg/<قناة>/<k>.json` | منشورات القناة كاملة، مقسّمة إلى ملفات صغيرة | ~٤٠٠ ك.ب للملف |
| `data/youtube.json` | مقاطع يوتيوب وقوائم التشغيل | ~١ م.ب |
| `data/tg/files.json` | داخلي: حالة نسخ الملفات إلى R2. **لا يعتمد عليه التطبيق**، فالروابط مدمجة في المنشورات | — |
| `data/sources.json` | داخلي: إعدادات المزامنة | — |

### تحميل منشورات قناة

يقع المنشور رقم `n` في الملف `k = floor(n / shard)`، وقيمة `shard` في الفهرس (حالياً 500).

- **قائمة ملفات القناة:** `channels[<قناة>].shards`، مرتبة من الأحدث، مثل `[12, 11, …, 0]`.
- **لعرض أحدث المنشورات:** حمّل الملف الأول من القائمة.
- **لعرض منشور معيّن:** معرّفه `tg:quraangroup/6246`، فهو في `data/tg/quraangroup/12.json`.

داخل كل ملف: `{"items": [ … ]}`، والمنشورات فيه مرتبة من الأحدث إلى الأقدم.

## المنشور (من تليجرام)

| الحقل | النوع | الوصف |
|---|---|---|
| `id` | نص | **ثابت.** `tg:<قناة>/<رقم>`، مثل `tg:fawaid_alsiar/491` |
| `n` | عدد | رقم المنشور في قناته |
| `type` | نص | `article` فائدة نصية، أو `book` كتاب من تأليف الشيخ، أو `file` ملف برنامج (PDF)، أو `audio` صوت، أو `video` مقطع. وقد تظهر `other`، وهي مادة لغير الشيخ: **لا تعرضها**، والموقع يخفيها |
| `title` | نص | العنوان |
| `text` | نص | النص الكامل. الأسطر مفصولة بـ `\n`، وقد يحوي روابط |
| `date` | نص | تاريخ النشر |
| `source` | نص | `tg:<قناة>` |
| `url` | نص | رابط المنشور في تليجرام (احتياطي) |
| `tags` | مصفوفة نصوص | الوسوم بلا `#` |
| `week` | عدد | رقم أسبوع برنامج الحفظ (قناة `quraangroup` فقط) |
| `youtube` | نص | معرّف مقطع يوتيوب إن كان المنشور مقطعاً |
| `doc` | نص | اسم الملف الأصلي في تليجرام |
| `size` | نص | الحجم كما يعرضه تليجرام، مثل `"2.9 MB"`، للعرض فقط |
| **`file_url`** | نص | **رابط الملف المباشر من R2** للكتب والملفات والصوتيات. يعمل دون تليجرام، ويدعم التحميل الجزئي (Range) |
| **`file_size`** | عدد | حجم الملف بالبايت |
| **`file_mime`** | نص | نوع الملف، مثل `application/pdf` و`audio/mp4` |
| **`file_name`** | نص | اسم الملف للتحميل |
| **`image_url`** | نص | رابط مطلق لصورة المنشور (محفوظة في الموقع)، أو للصورة المصغّرة للمقطع |
| `img` | نص | قديم: مسار نسبي للصورة. استعمل `image_url` |
| `photo` | نص | قديم: رابط صورة من خوادم تليجرام، **تنتهي صلاحيته**. لا تعتمد عليه |
| `thumb` | نص | صورة مصغّرة من يوتيوب |

**فتح الملف:** إن وُجد `file_url` فهو الأساس، وإلا فـ `url` (تليجرام). الملفات الأكبر من ٢٠ ميجابايت قد يتأخر وصولها إلى R2، لأنها تُرفع يدوياً.

**الروابط التي يبنيها التطبيق بنفسه:**
- **صفحة المادة في الموقع:** `https://absaralislam.github.io/#/i/<id مرمّزاً>`، مثل `#/i/tg%3Afawaid_alsiar%2F491`.
- **صفحة الأسبوع:** `#/w/quraangroup/<رقم الأسبوع>`.

## الفهرس `data/tg/index.json`

```json
{
  "schema_version": 1,
  "site_url": "https://absaralislam.github.io",
  "files_base_url": "https://absar-files.….workers.dev",
  "shard": 500,
  "channels": { "<قناة>": { … } },
  "books": [ … ],
  "videos": [ … ]
}
```

### القناة `channels.<قناة>`

| الحقل | الوصف |
|---|---|
| `label` | اسم القناة للعرض |
| `program` | معرّف البرنامج في `library.json` |
| `count` | عدد المنشورات المعروضة (بلا `other`) |
| `types` | عدد كل نوع، مثل `{"article": 2565, "file": 934}` |
| `max` | رقم أحدث منشور |
| `shards` | أرقام ملفات المنشورات، من الأحدث |
| `latest` | أحدث الفوائد بصيغة مختصرة (انظر «المادة المختصرة») |
| `tags` | أكثر الوسوم: `[[الوسم, العدد], …]` |
| `weeks` | لقناة `quraangroup` فقط: أسابيع برنامج الحفظ، من الأحدث |

### الأسبوع `channels.quraangroup.weeks[]`

| الحقل | الوصف |
|---|---|
| `no` | رقم الأسبوع، وهو ثابت |
| `label` | اسمه، مثل «الأسبوع السابع والتسعين» |
| `passage` | المقطع القرآني، مثل «سورة الأنعام ١٥٥ - ١٦٥» |
| `from`, `to` | أول منشور وآخره في القناة |
| `start`, `end` | تاريخ البداية والنهاية |
| `count` | عدد منشوراته |
| `files` | ملفاته: `id` و`title` و`url` و`size` و`date` و`file_url` و`file_size` و`file_mime` |
| `videos` | مقاطعه: `id` و`youtube` و`date` |

### المادة المختصرة (في `latest` و`books` و`videos`)

`id` و`type` و`title` و`date` و`source` و`url` و`excerpt` (أول ١٨٠ حرفاً من النص)، وعند وجودها: `youtube` و`thumb` و`doc` و`size` و`file_url` و`file_size` و`file_mime` و`image_url`.

وفي `books` زيادة `series`: اسم السلسلة إن كان الكتاب منها، مثل «دروس التجويد (لمحة تجويدية)».

## يوتيوب `data/youtube.json`

```json
{ "schema_version": 1, "site": { "sources": { … } }, "playlists": [ … ], "items": [ … ] }
```

**المقطع `items[]`:**

| الحقل | الوصف |
|---|---|
| `id` | **ثابت.** `yt:<معرّف المقطع>` |
| `type` | `video` |
| `title` | العنوان |
| `date` | تاريخ النشر |
| `youtube` | معرّف المقطع: يُشغَّل برابط `https://www.youtube.com/watch?v=<youtube>` أو بمشغّل مضمّن |
| `url` | رابط المقطع على يوتيوب |
| `image_url`, `thumb` | الصورة المصغّرة |
| `summary` | وصف المقطع (اختياري) |
| `length` | المدة نصاً (اختياري) |
| `program` | معرّف البرنامج |
| `playlists` | معرّفات قوائم التشغيل التي يتبعها |

**قائمة التشغيل `playlists[]`:**

| الحقل | الوصف |
|---|---|
| `id` | معرّف القائمة في يوتيوب |
| `title` | اسمها |
| `program` | معرّف البرنامج |
| `videos` | معرّفات مقاطعها (`yt:…`) |
| `week` | رقم الأسبوع إن كانت قائمة أسبوع |

## بيانات الموقع `data/library.json`

- **`site`:** الاسم، واسم الشيخ، والنص التعريفي، ورابط التواصل.
- **`programs[]`:** البرامج، ولكل برنامج:
  - `id` (ثابت)
  - `title` و`description`
  - `youtube`: رابط القناة (اختياري)
  - `playlistGroups`: قواعد تجميع قوائم التشغيل (اختياري)

  أما ربط القنوات بالبرامج فيأتي من `channels.<قناة>.program` في الفهرس.
- **`fawaid`:** القنوات التي يجمعها تبويب «الفوائد»، بالترتيب.
- **`cv[]`:** محطات السيرة الذاتية، ولكل محطة:
  - `year` و`title` و`place` و`text`
  - `links[]`: إما `{t, id}` لمادة في المكتبة، أو `{t, href}` لرابط.
- **`items[]`:** مواد مضافة يدوياً (الصيغة نفسها).

## التخزين المؤقت والتحديث

- **ملفات JSON:** تُقدَّم من GitHub Pages. اطلبها مع `Cache-Control: no-cache` أو باختبار `ETag`، فتصلك نسخة محدَّثة بلا كلفة إن لم تتغير.
- **ملفات R2:** لا تتغير أبداً، لأن اسمها بصمة محتواها، فخزّنها محلياً بلا انتهاء. وإن تغيّر ملف في القناة صار له رابط جديد.
- **اكتشاف الجديد:** قارن `channels.<قناة>.max` بآخر قيمة حفظتها.
